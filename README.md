## 项目简介

**TADS（Train Arrival & Departure Service System）列车数据与查询服务系统** 是由 **QS Studio** 研发的一套面向轨道交通行业的企业级运营数据中台解决方案。系统采用客户端/服务器（C/S）架构，提供轻量级、易部署、权限可控的列车运行数据管理与综合查询服务。

TADS 深度整合了多源铁路运营数据（图定时刻表、实时正晚点、动车组交路、编组信息等），构建了从物理密钥认证到数据访问的端到端安全防护体系，适用于铁路局、地铁公司、物流企业及轨道交通相关部门的日常运营数据管理与决策支持场景。

系统包含三大核心组件：
- **TADS 服务端**（`TADS_server.py`）：核心数据中台与 API 服务引擎
- **TADS 客户端**（`TADS_client.py`）：远程综合查询终端
- **TADS 物理密钥及密码管理系统**（`TADS-Key_Manager.py`）：独立的密钥与密码管理工具 — **QS Studio Security Lab** 出品

## 核心特性

### 一、数据管理

| 功能 | 说明 |
|------|------|
| **车次增删改查** | 支持新增、删除车次，自动分配唯一 train_id |
| **停站录入删除** | 为车次添加/删除经停站，自动维护始发站与终点站 |
| **合并车次组管理** | 自动识别复车次（如 K973/K976），合并显示为 K973/K976 |
| **数据持久化** | JSON 格式存储，支持手动备份与还原点恢复 |
| **批量导入/更新** | 支持通过 V1/V2 接口抓取车次全部经停站，本地存在则更新，不存在则新增 |
| **车站抓取** | 输入车站名，自动抓取该站所有车次并导入本地数据库 |

### 二、综合查询中心 — QS Studio Query Engine

TADS 内置了由 **QS Studio** 设计的 **双引擎实时查询架构**，支持本地数据与 API 实时数据无缝切换，涵盖 9 大类专业查询场景：

| 查询类型 | 说明 |
|----------|------|
| **车次停站数量** | 快速查看车次停靠站数，同步展示完整列车技术参数（车型、路局、配属、担当、运行时长） |
| **车次全部经停详情** | 全维度停站信息展示：站名、到达/出发时刻、跨天标识、本站车次、站台、检票口、出站口、实时正晚点状态 |
| **某站经过的所有车次** | 查询经过某站的全部车次（含合并组），支持双击穿透查看详情 |
| **站点时刻表** | 智能时刻表展示：当前时间、上一班/下一班（自动识别昨日/次日）、按时间排序的所有经停车次 |
| **车次/站点匹配校验** | 快速验证指定车次是否经停某站 |
| **全局搜索引擎** | 关键词全文检索车次/车站，支持模糊匹配 |
| **车次当前理论位置** | 基于实际时刻表与正晚点偏移，实时推算列车当前位置与区间运行状态，显示距发车/到达剩余时间 |
| **两站间今日列车运行** | 智能查询两站间所有车次及运行状态，自动识别"刚过掉"和"马上进入"的车次 |
| **车站↔车次双向查询** | 车次→始发/终点、起始站→所有始发车次（含终点、出发时间、类型）、起点+终点→车次（含正晚点） |

### 三、实时数据融合

| 功能 | 说明 |
|------|------|
| **实时正晚点查询** | 调用 V2 接口获取列车实时正晚点数据，显示晚点/提前分钟数，标注是否已过该站，支持"预计正点"、"预计晚点"等预测状态 |
| **车站大屏** | 实时获取车站大屏数据（出发/到达），显示车次、始发站、终点站、图定时间、大屏状态、检票口/出站口、晚点/提前附加信息 |
| **双模式切换** | 本地模式（服务器本地数据）+ API 模式（V1/V2 实时数据）一键切换，切换后自动刷新当前查询结果 |

### 四、车次详情页 — QS Studio 智能信息聚合

| 信息类别 | 内容 |
|----------|------|
| **列车技术参数** | 车次、类型、复车次、路局、车型、配属、担当、运行时长 |
| **运行停站列表** | 站名、到达、出发、跨天、本站车次、站台、检票口、出站口 |
| **实时正晚点** | 实时查询，未过站自动添加"预计"前缀标识 |
| **列车组图片** | 展示列车车厢分布图，车厢图片双击放大查看，显示列车技术参数 |
| **动车组运行查询** | 查询车次/车组运行信息（运行日期、车次、车组号、是否重联），双击查看车组详细信息 |
| **车组详细信息** | 卡片式可视化展示：基本信息（车组号、车型、子型号、自定义类型、生产时间）、配属信息（所属局、所属段、动车制造商等）、设施信息（商务座类型、电源位置、厕所类型等）、备注信息 |

### 五、权限与安全体系 — QS Studio Security Framework

#### 5.1 四级权限体系

| 身份 | 权限范围 |
|------|----------|
| **普通用户** | 仅查询功能（所有查询模块可用） |
| **TADS Developer** | 开发者身份标识，可进入编辑/设置/日志/还原点界面 |
| **TADS Administrator** | 固定权限：新增车次、录入停站、添加还原点、导出日志、查看配置、更改管理员密码、更新数据（不含任何删除、更改配置操作） |
| **TADS Root** | 全权（所有功能，含删除、格式化、更改 ROOT 密码等） |

#### 5.2 物理密钥认证系统 — QS Studio Secure NFC

> **QS Studio 完全自研 PN532 驱动** — 系统内置了由 **QS Studio Hardware Lab** 研发的、经过充分测试的 PN532 NFC 读卡器驱动程序，支持 M1 卡和 NTAG215 卡的识别与验证，无需第三方依赖即可完成卡片读写操作。

| 卡类型 | 认证方式 |
|--------|----------|
| **管理员 M1 卡** | 4字节 UID 验证，支持多卡名单（逗号分隔） |
| **ROOT NTAG215 卡** | 7字节 UID + Ed25519 签名验证，支持多卡名单（逗号分隔） |
| **开发者卡** | 专属密码认证（配置文件中独立存储） |

**认证流程：**
1. 输入密码
2. 系统比对密码哈希（SHA256 + 16字节盐）
3. 密码匹配后，自动检测物理密钥
4. 验证 UID 是否在授权名单中
5. 验证通过 → 提权成功

#### 5.3 配置版本监控（防会话劫持）

- 管理员/ROOT 登录后，后台线程每 5 秒轮询 `config.json` 中的 `config_version`
- 检测到版本变更时，自动强制退出登录，回退到普通用户
- 自动关闭所有敏感标签页（编辑、设置、日志、还原点）
- 弹出提示框要求重新登录

#### 5.4 专属密码系统

- 每个物理密钥（UID）可设置独立专属密码
- 密码使用 AES-256-CBC 加密存储（密钥固定，32字节）
- 支持管理员/ROOT 通过 API 查询指定 UID 的专属密码

### 六、TADS 物理密钥及密码管理系统 — QS Studio Security Lab

`TADS-Key_Manager.py` 是 **QS Studio Security Lab** 研发的独立密钥管理工具，用于集中管理所有物理密钥和对应的密码：

| 功能 | 说明 |
|------|------|
| **密钥管理** | 查看、添加、删除、启用/禁用物理密钥（UID） |
| **密码管理** | 为每个密钥设置/清空专属密码，支持显示/隐藏/复制密码 |
| **权限管理** | 调整密钥的权限等级（Administrator / ROOT / Both / Developer） |
| **UID 管理** | 支持修改已注册密钥的 UID（换卡场景） |
| **通用密码管理** | 设置/清空 Administrator 和 ROOT 的通用密码 |
| **实时读卡** | 集成 QS Studio 自研 PN532 驱动，一键读取卡片 UID 自动填入 |
| **使用日志查询** | 查询每个 UID 在最近 4 小时内的使用次数（用于审计追踪） |
| **安全显示** | UID 和密码默认脱敏显示（******），右键菜单可临时显示/复制 |
| **搜索定位** | 按 UID 快速搜索并定位到指定密钥 |

> 该工具需 ROOT 密码验证后方可进入，确保只有最高权限用户才能管理密钥体系。

### 七、日志审计系统 — QS Studio Audit Trail

| 功能 | 说明 |
|------|------|
| **操作日志** | 记录所有关键操作（登录、提权、数据变更、查询、还原点操作、API 调用） |
| **错误日志** | 独立记录系统异常和 API 错误 |
| **日志查看** | 支持普通日志和报错日志切换查看，显示最近 3000 行 |
| **日志导出** | 支持 CSV / JSON / TXT 三种格式导出 |
| **日志保存** | 支持将当前日志内容保存到文件 |
| **日志清空** | 支持清空指定类型的日志（仅 ROOT） |

### 八、还原点系统

| 功能 | 说明 |
|------|------|
| **添加还原点** | 上限 3 个，自动备份当前数据 |
| **从还原点恢复** | 选择还原点恢复数据 |
| **编辑还原点** | 删除或重命名现有还原点 |
| **格式化所有还原点** | 一次性清空所有还原点 |

### 九、API 服务引擎 — QS Studio API Gateway

| 功能 | 说明 |
|------|------|
| **完整 HTTP API** | 为客户端提供完整的 RESTful API 接口 |
| **V1/V2 接口代理** | 内置代理，避免客户端跨域问题 |
| **EMU API 代理** | 动车组运行查询和配属详细信息查询代理 |
| **双模式支持** | 支持客户端本地模式和 API 模式切换 |
| **权限控制** | 所有敏感操作需管理员/ROOT 权限 |

## 快速开始

### 服务端部署

**前置条件：**
- Windows 7/10/11（推荐以管理员身份运行）
- 固定局域网IP地址（供客户端访问）
- PN532 NFC 读卡器（如需物理密钥认证）

**步骤：**

```bash
# 1. 下载 TADS_server.exe
# 2. 以管理员身份运行
右键 TADS_server.exe → "以管理员身份运行"

# 3. 确认启动成功
# 控制台显示 "TADS API 服务启动（独立运行版）"
# 界面显示主窗口，状态栏显示 "API服务：正常运行"
```

服务端启动后，数据目录自动创建于 `E:\数据库\TADS_Data\`。

**首次使用需进行管理员提权：**
- 点击左侧导航栏 "提权"
- 点击 "TADS administrator"
- 输入预设管理员密码 + 刷管理员 M1 卡

---

### 客户端部署

**前置条件：**
- Windows 7/10/11
- 能够访问服务端 IP 和端口 10076

**步骤：**

```bash
# 1. 下载 TADS_client.exe
# 2. 配置服务器地址（设置界面可修改）
# 3. 双击运行
```

> 客户端为绿色软件，无需安装，本地不存储任何数据（除客户端配置文件外）。

## 配置说明

### 服务端配置文件结构

```
%APPDATA%\TADS\Server\config\
├── config.json              # 主配置文件
├── .env                     # 环境变量（密钥对、UID名单）
└── key_status.env           # 物理密钥状态（UID|卡类型|权限|姓名|启用状态）
```

### config.json 主要字段

| 字段 | 说明 |
|------|------|
| `admin_password_hash` | 管理员通用密码哈希（Base64） |
| `root_password_hash` | ROOT 通用密码哈希（Base64） |
| `developer_password_hash` | 开发者通用密码哈希（Base64） |
| `physical_keys` | 物理密钥名单（UID、类型、人员） |
| `uid_passwords` | UID 专属密码（AES-256-CBC 加密） |
| `uid_encryption_key` | UID 加密固定密钥（Base64） |
| `config_version` | 配置版本号（每次密钥/密码变更递增） |
| `api` | V1/V2/EMU API 接口地址 |
| `monitor` | 中枢站监控配置（端口、显示名称） |

### 客户端服务器地址配置

客户端默认服务器地址为 `192.168.100.101:10076`，可在设置界面修改，或修改 `client_config.json`：

```json
{
  "server_ip": "192.168.100.101",
  "server_port": 10076,
  "com_port": "COM4",
  "baudrate": 115200
}
```

### 数据目录修改（服务端）

服务端默认数据目录为 `E:\数据库\TADS_Data\`，可在设置界面 → 路径配置中修改。

### 端口修改

默认 API 端口为 `10076`，可在设置界面 → 更改 API 服务端口中修改，修改后需重启服务端生效。

## API概览

### 基础接口

| 方法 | 路径 | 认证 | 说明 |
|------|------|------|------|
| GET | `/` | 无 | 服务信息与端点列表 |
| GET | `/api/health` | 无 | 健康检查 |
| GET | `/api/stats` | 无 | 统计信息 |
| GET | `/api/trains` | 无 | 所有车次（精简） |
